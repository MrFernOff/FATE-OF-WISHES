# ✦ Fate of Wishes

**Личный планировщик круток для Genshin Impact.** Помогает понять, хватит ли у тебя примогемов на желаемый баннер, сколько фармить в день и когда стоит придержать ресурсы до следующего ивента.

Никаких аккаунтов, серверов и трекинга — всё живёт в `localStorage` твоего браузера.

## Возможности

- **Календарь фарма** — отмечай, сколько примогемов получил и сколько круток потратил в каждый день; на клетках сразу видно баланс дня.
- **Расчёт баннера** — обратный отсчёт до конца баннера, прогресс-бар по времени, сколько примогемов ещё нужно и сколько нужно фармить в день, чтобы успеть. Есть три режима: текущий баннер, следующий баннер, все цели подряд.
- **Smart Farm** — сравнивает твой средний темп фарма с необходимым и подсказывает, успеваешь ты или нужно ускориться.
- **Свои цели** — можно добавлять произвольные баннеры/цели с датами и стоимостью в крутках, помимо встроенного календаря официальных баннеров.
- **Учёт pity и гаранта** — ручной ввод текущего pity (0–90) и состояния 50/50 / гарант.
- **Подробный лог** — полная история операций с возможностью удаления записи (баланс и pity пересчитываются автоматически).
- **Экспорт / импорт** — весь прогресс можно сохранить в `.json` и перенести на другое устройство.

## Технологии

Один HTML-файл, без зависимостей и сборки:

- чистый JavaScript (ES6+)
- CSS-переменные для темы
- `localStorage` для хранения данных
- инлайновый SVG-спрайт с иконками в стиле Genshin (примогемы, Intertwined Fate и т.д.) вместо эмодзи

## Обновление баннеров

Расписание баннеров подтягивается автоматически из неофициального фан-API [`hoyoverse-api`](https://github.com/torikushiii/hoyoverse-api) — он зеркалит официальный игровой календарь событий (то, что HoYoverse уже анонсировали в игре). Руками ничего вписывать не нужно.

Как это работает:

- при загрузке страница мгновенно показывает то, что уже есть (кэш из `localStorage` или зашитый в код список), а в фоне тихо запрашивает свежие данные
- если API отвечает — баннеры обновляются, значок на карточке меняется на «✓ OFFICIAL», результат кладётся в кэш
- если API недоступен (упал, лимит запросов, заблокирован CORS) — приложение молча остаётся на кэше/зашитом списке со значком «◇ ESTIMATED», ничего не ломается

Личную цель в круткax (сколько именно тянуть на баннер) API не знает — это решаешь ты. По умолчанию ставится 90 (один гарант), поменять можно кнопкой-шестерёнкой рядом со строкой «Цель» в карточке «Расчёт баннера».

Если фан-API когда-нибудь перестанет существовать, зашитый в код запасной список (`FALLBACK_BANNERS` в начале `<script>`) — единственное, что придётся обновлять руками, и только как аварийный вариант.

## Данные и приватность

Все данные (баланс, pity, лог операций, свои цели) хранятся **только локально**, в `localStorage` браузера. Ничего не отправляется на сервер. Очистка кэша браузера или кнопка «Сброс» в приложении удаляют прогресс без возможности восстановления — не забывай делать экспорт.
